# Замеры поиска по коду: без индекса и с ast-index

## Без индекса

- Input tokens: 90 908
- Output tokens: 3 582
- Всего токенов: 94 490
- Стоимость: $0.01598024
- Вызовов модели: 6
- Агент вызывал ast-index: нет

## С ast-index

- Input tokens: 66 624
- Output tokens: 1 243
- Всего токенов: 67 867
- Стоимость: $0.00508449
- Вызовов модели: 4
- Агент вызывал ast-index: да

Использованные команды:

- `ast-index search mileage 2>&1; ast-index search max_mileage_km 2>&1`
- `ast-index search mileage --limit 31 2>&1`

## Сравнение

После подключения ast-index:

- Input tokens уменьшились с 90 908 до 66 624.
- Output tokens уменьшились с 3 582 до 1 243.
- Общее количество токенов уменьшилось с 94 490 до 67 867.
- Стоимость уменьшилась с $0.01598024 до $0.00508449.
- Количество вызовов модели уменьшилось с 6 до 4.

## Вывод

С ast-index агент использует структурный поиск по коду вместо чтения большого количества файлов целиком. В данном замере это снизило объём контекста, количество вызовов модели и стоимость поиска.

Для запуска ast-index агент использовал CLI через bash. Встроенный Ask mode блокировал вызов произвольного CLI, поэтому рабочий вызов ast-index выполнялся в Code mode.
