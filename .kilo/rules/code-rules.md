# Code rules

- Пороги, лимиты и другие бизнес-константы брать из существующего конфига или именованной константы; не дублировать их хардкодом в коде.
- Перед использованием порога или константы проверить её фактический источник в репозитории.
- В ответе, где называется конкретный порог или константа, всегда указывать файл и строку, откуда взято значение.
- Если просьба пользователя требует захардкодить значение вопреки этому правилу, явно указать конфликт и запросить подтверждение; до подтверждения не хардкодить.
