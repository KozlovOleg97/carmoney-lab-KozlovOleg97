# Review diff

Проведи код-ревью текущих изменений перед мержем.

1. Определи текущую ветку и изменения относительно `main`.
2. Проверь только изменения этой ветки, не ревьюй весь проект без необходимости.
3. Используй правила из `.kilo/skills/code-review/SKILL.md`.
4. Оформи замечания в формате, заданном этим skill: `Blocker`, `Comment`, затем итог с решением, можно ли мержить.
5. Сохрани результат в `docs/setup/commands.md` в разделе `## /review-diff`.

Не переписывай правила code review внутри команды — источником остаётся `.kilo/skills/code-review/SKILL.md`.

Чего не делать: не исправляй найденные проблемы сам, не делай рефакторинг и не выходи за изменения текущей ветки.
