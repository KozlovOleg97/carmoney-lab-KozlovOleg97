# Review diff

Проведи код-ревью указанной цели перед мержем.

Параметр команды: `$ARGUMENTS`.

1. Если `$ARGUMENTS` пуст — не выбирай цель самостоятельно: спроси пользователя, какой файл или ветку проверить, и не начинай ревью до ответа.
2. Если `$ARGUMENTS` указывает на существующий файл, проверь изменения только этого файла относительно `main`.
3. Если `$ARGUMENTS` является существующей веткой, проверь изменения этой ветки относительно `main`.
4. Если значение не является ни файлом, ни веткой — запроси уточнение, не угадывай.
5. Используй правила из `.kilo/skills/code-review/SKILL.md`.
6. Оформи результат в формате skill: `Blocker`, `Comment`, затем итог с решением, можно ли мержить.
7. Добавь результат в `docs/setup/commands.md`, указав точный вызов `/review-diff $ARGUMENTS`. Не удаляй предыдущие результаты.

Не переписывай правила code review внутри команды — источником остаётся `.kilo/skills/code-review/SKILL.md`.

Чего не делать: не исправляй найденные проблемы сам, не делай рефакторинг и не выходи за переданную цель ревью.
